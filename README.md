# Python 并发编程

Python 并发编程学习项目，涵盖进程、线程、协程与锁四大主题，配套完整学习文档与可运行的示例代码。

## 目录结构

```
.
├── process/       # 进程（multiprocessing）
├── thread/        # 线程（threading）
├── lock/          # 锁与竞争条件
└── 学习文档.md     # 完整学习文档
```

## 目录说明

- **process/**　进程相关示例：单任务、多进程、多进程传参、获取进程编号、守护进程、多进程复制文件案例
- **thread/**　线程相关示例：多线程、线程传参、守护线程、线程执行顺序
- **lock/**　锁与竞争条件示例：计数器、银行取款、锁修复、with 写法、死锁、可重入锁
- **学习文档.md**　完整的学习文档，口语化讲解进程、线程、协程、竞争条件与锁

## 快速开始

所有示例均为 Python 标准库实现，无需安装第三方依赖，直接运行即可，例如：

```bash
python "process/1. 单任务.py"
```
